Yes—this is absolutely possible on a very low or even zero initial budget. Because your site already runs through Cloudflare, you are unusually well positioned to do it cheaply.

The sensible first version would not involve literally training a new model. Instead, it would combine:

An existing small language model.
A carefully written personality and behavioural prompt.
A searchable knowledge collection containing your lore, site information, books, development notes, album descriptions, FAQs, and whatever else you approve.

That approach is called retrieval-augmented generation, or RAG. When someone asks a question, the system searches your approved documents, gives the relevant passages to the model, and asks it to answer from them. To visitors, it still feels like an AI that “knows your work.”

Best approach for your site

I would build it approximately like this:

Website chat drawer
A small button appears at the side or bottom of the site. Clicking it slides open a chat panel. The same responsive component can work on desktop and mobile; mobile may actually be simpler because it can open almost full-screen.

Cloudflare Worker backend
The browser sends messages to a Worker. The Worker protects your credentials, applies rate limits, retrieves relevant knowledge, and calls the model. No AI keys should ever be placed directly in your public JavaScript.

Cloudflare Workers AI
Cloudflare currently provides 10,000 AI Neurons per day free, after which requests simply fail on the free plan rather than silently producing a bill. Its smaller Llama models are inexpensive enough that this could plausibly support hundreds of modest conversations each day, depending heavily on response length and how much document material is included in each request.

Cloudflare Vectorize
Later, your documents can be split into passages and indexed for semantic search. Its free tier presently includes 5 million stored vector dimensions and 30 million queried dimensions monthly—enough for a meaningful prototype and probably a substantial personal knowledge archive if we chunk it intelligently.

Optional D1 database
You already use D1 for likes. It could also store conversation sessions, anonymous visitor identifiers, feedback, daily usage, and a list of blocked users. The free plan currently includes generous daily read/write allowances and 5 GB total storage.

What version one could know

We could begin with a deliberately limited AI that knows perhaps:

What Loki’s Kingdom is.
Your game’s mechanics, factions, characters, and lore.
Your albums, song series, website rooms, and projects.
Approved biography and company information.
Frequently asked questions.
Selected books, deepdives, developer notes, or manifestos.
How to direct visitors to the jukebox, APK, game, archive, and other sections.

It could also have a distinct name, speaking style, worldview, greeting, avatar, and role. For example, it might present itself as an archivist, librarian, oracle, demon, curator, or guide rather than as a generic customer-service bot.

The important distinction is that we would only index material you explicitly approve. Your private screenshots, passwords, addresses, legal evidence, and sensitive archive files should not enter the public knowledge source.

A genuinely tiny first prototype

The first version does not even need Vectorize.

We could give the model:

A permanent system prompt describing its personality.
A manually prepared knowledge file containing perhaps 20–100 important facts.
The visitor’s recent chat history.

That would be enough to create a real working assistant. It would not search thousands of documents yet, but it could discuss your main projects quite convincingly. We could later replace the fixed knowledge block with proper document retrieval without rebuilding the interface.

A sensible progression would be:

Stage 1 — approximately zero cost

Sliding chat panel.
Text chat only.
One small Cloudflare AI model.
Handwritten personality prompt.
A compact curated knowledge document.
Daily and per-user message limits.
No permanent chat history.
Clear “AI may be inaccurate” notice.

Stage 2 — still potentially zero cost

Vectorize document search.
Citations or “sources consulted” beneath answers.
More of your lore and development archive.
Visitor conversation history.
Feedback buttons.
Administrator analytics.

Stage 3 — optional expenses

Better or larger models.
Accounts and persistent memories.
Speech recognition.
High-quality generated voice.
Agent abilities, such as searching the site or controlling the jukebox.
Voice versus text

“Talk” can mean two different things:

Chat in text: straightforward and cheap.
Actually speak and listen: possible, but better postponed.

Browser text-to-speech can read answers aloud without a commercial voice API, although voices differ by operating system and browser. Speech recognition is less consistent across browsers and may involve browser-vendor services. A polished custom voice would normally create an additional API cost.

I would therefore begin with text chat plus an optional Read Aloud button. That gives it a voice-like presence without making voice infrastructure a prerequisite.

Important limitations

A zero-budget public chatbot needs hard boundaries:

Maximum prompt and response lengths.
Perhaps 10–20 messages per visitor daily at first.
CAPTCHA or other bot protection.
A global daily cutoff before the free AI allowance is exhausted.
No unrestricted uploading of documents.
No promises that its statements represent you personally.
No public access to confidential source material.
Prompt-injection protection, although no protection is perfect.

It should also be instructed to distinguish between established information, fictional lore, your stated opinions, and uncertain material. That will matter with a large archive containing fiction, jokes, mythology, development notes, and autobiographical writing.

My recommendation

For lokiskingdom.com, I would use:

Astro chat drawer → Cloudflare Worker → Workers AI → curated knowledge file, followed later by Vectorize.

That is probably the lowest-cost and least disruptive route available to you. It fits your existing infrastructure, does not require maintaining a GPU server, and allows us to create something genuinely functional before attempting a massive archive ingestion.

The first useful version is considerably smaller than building the jukebox or Android app. The interface itself is not the difficult part. The most important work would be defining who the AI is, what it is allowed to know, and how it should handle conflicting or sensitive material.

function jsonResponse(body, status = 200, extraHeaders = {}) {
  return new Response(JSON.stringify(body), {
    status,
    headers: {
      "Content-Type": "application/json; charset=utf-8",
      "Cache-Control": "no-store",
      ...extraHeaders
    }
  });
}

function normalizeMessages(value) {
  if (!Array.isArray(value)) {
    return [];
  }

  return value
    .filter((message) => {
      return (
        message &&
        typeof message.content === "string" &&
        (message.role === "user" || message.role === "assistant")
      );
    })
    .slice(-MAX_HISTORY_MESSAGES)
    .map((message) => ({
      role: message.role,
      content: message.content.slice(0, MAX_USER_MESSAGE_LENGTH)
    }));
}

function containsForbiddenName(text, env) {
  const configuredNames = env.FORBIDDEN_NAMES || "";

  const forbiddenNames = configuredNames
    .split("|")
    .map((name) => name.trim().toLowerCase())
    .filter(Boolean);

  const normalizedText = text.toLowerCase();

  return forbiddenNames.some((name) => normalizedText.includes(name));
}

function getCorsHeaders(request, env) {
  const origin = request.headers.get("Origin") || "";
  const allowedOrigin = env.ALLOWED_ORIGIN || "*";

  // Native Android requests often have no browser Origin header.
  if (!origin) {
    return {
      "Access-Control-Allow-Origin": allowedOrigin
    };
  }

  if (allowedOrigin === "*" || origin === allowedOrigin) {
    return {
      "Access-Control-Allow-Origin": allowedOrigin
    };
  }

  return {};
}

export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    const corsHeaders = getCorsHeaders(request, env);

    if (request.method === "OPTIONS") {
      return new Response(null, {
        status: 204,
        headers: {
          ...corsHeaders,
          "Access-Control-Allow-Methods": "POST, OPTIONS",
          "Access-Control-Allow-Headers":
            "Content-Type, Authorization, X-App-Key",
          "Access-Control-Max-Age": "86400"
        }
      });
    }

    if (url.pathname !== "/chat") {
      return jsonResponse(
        { error: "Not found." },
        404,
        corsHeaders
      );
    }

    if (request.method !== "POST") {
      return jsonResponse(
        { error: "Method not allowed." },
        405,
        corsHeaders
      );
    }

    /*
     * This is suitable for an admin-only prototype, but it is not perfect
     * security because a key inside an APK can eventually be extracted.
     * Later, replace it with Cloudflare Access or another authentication flow.
     */
    const suppliedAppKey = request.headers.get("X-App-Key");
    const requiredAppKey = env.APP_KEY;

    if (requiredAppKey && suppliedAppKey !== requiredAppKey) {
      return jsonResponse(
        { error: "The passage is sealed." },
        401,
        corsHeaders
      );
    }

    let body;

    try {
      body = await request.json();
    } catch {
      return jsonResponse(
        { error: "Invalid JSON." },
        400,
        corsHeaders
      );
    }

    const message =
      typeof body.message === "string"
        ? body.message.trim()
        : "";

    if (!message) {
      return jsonResponse(
        { error: "No message was provided." },
        400,
        corsHeaders
      );
    }

    if (message.length > MAX_USER_MESSAGE_LENGTH) {
      return jsonResponse(
        {
          error: "The spirit cannot hear speeches that long."
        },
        413,
        corsHeaders
      );
    }

    const currentStrikes = Math.max(
      0,
      Math.min(Number(body.strikes) || 0, 2)
    );

    if (containsForbiddenName(message, env)) {
      const newStrikes = currentStrikes + 1;

      if (newStrikes >= 2) {
        return jsonResponse(
          {
            reply:

            blocked: true
          },

        );

          blocked: false
        },

class SpiritViewModel(
    private val repository: SpiritRepository
) : ViewModel() {

    var state by mutableStateOf(SpiritUiState())
        private set

    fun updateInput(value: String) {
        if (!state.blocked) {
            state = state.copy(input = value)
        }
    }

    fun sendMessage() {
        val message = state.input.trim()

        if (
            message.isBlank() ||
            state.isLoading ||
            state.blocked
        ) {
            return
        }

        val previousMessages = state.messages

        state = state.copy(
            messages = previousMessages + SpiritMessage(
                role = "user",
                content = message
            ),
            input = "",
            isLoading = true,
            error = null
        )

        viewModelScope.launch {
            try {
                /*
                 * Send the previous conversation only.
                 * The current message is passed separately.
                 */
                val response = repository.sendMessage(
                    message = message,
                    history = previousMessages,
                    strikes = state.strikes
                )

                state = state.copy(
                    messages = state.messages + SpiritMessage(
                        role = "assistant",
                        content = response.reply
                    ),
                    strikes = response.strikes,
                    blocked = response.blocked,
                    isLoading = false
                )
            } catch (error: Exception) {
                state = state.copy(
                    isLoading = false,
                    error = error.message
                        ?: "The voice has disappeared."
                )
            }
        }
    }

    fun clearConversation() {
        state = SpiritUiState()
    }

async function handleChat(request, env) {
  let body;

  try {
    body = await request.json();
  } catch {
    return jsonResponse(
      { error: "Invalid request." },
      400
    );
  }

  const message =
    typeof body.message === "string"
      ? body.message.trim()
      : "";

  const history =
    Array.isArray(body.history)
      ? body.history
          .filter((item) => {
            return (
              item &&
              (item.role === "user" || item.role === "assistant") &&
              typeof item.content === "string"
            );
          })
          .slice(-12)
          .map((item) => ({
            role: item.role,
            content: item.content.slice(0, 700)
          }))
      : [];

  if (!message) {
    return jsonResponse(
      { error: "No message was provided." },
      400
    );
  }

  if (message.length > 700) {
    return jsonResponse(
      { error: "The message is too long." },
      413
    );
  }

  const messages = [
    {
      role: "system",
      content: SALLY_PROMPT
    },
    ...history,
    {
      role: "user",
      content: message
    }
  ];

  try {
    const result = await env.AI.run(MODEL, {
      messages,
      max_tokens: 300,
      temperature: 0.9
    });

    const raw =
      typeof result?.response === "string"
        ? result.response.trim()
        : "";

    const parsed = parseSallyResponse(raw);

    return jsonResponse(parsed);
  } catch (error) {
    console.error("Workers AI error:", error);

    return jsonResponse(
      {
        type: "reply",
        text:
          "The voice falters. For a moment, there is only scratching inside the wall."
      },
      502
    );
  }
}

function parseSallyResponse(raw) {
  try {
    const cleaned = raw
      .replace(/^```json/i, "")
      .replace(/^```/, "")
      .replace(/```$/, "")
      .trim();

    const parsed = JSON.parse(cleaned);

    if (
      parsed.type === "death" &&
      typeof parsed.text === "string" &&
      parsed.text.trim()
    ) {
      return {
        type: "death",
        text: parsed.text.trim()
      };
    }

    if (
      parsed.type === "reply" &&
      typeof parsed.text === "string" &&
      parsed.text.trim()
    ) {
      return {
        type: "reply",
        text: parsed.text.trim()
      };
    }
  } catch {
    // Fall through and treat malformed output as an ordinary reply.
  }

  return {
    type: "reply",
    text:
      raw || "Sally does not answer. Something else breathes nearby."
  };
}

}

async function handleChat(request, env) {
  let body;

  try {
    body = await request.json();
  } catch {
    return jsonResponse(
      {
        error: "Invalid request."
      },
      400
    );
  }

  const message =
    typeof body.message === "string"
      ? body.message.trim()
      : "";

  const turnNumber =
    Number.isFinite(Number(body.turnNumber))
      ? Math.max(
          1,
          Math.min(
            Number(body.turnNumber),
            100
          )
        )
      : 1;

  const history =
    Array.isArray(body.history)
      ? body.history
          .filter((item) => {
            return (
              item &&
              (
                item.role === "user" ||
                item.role === "assistant"
              ) &&
              typeof item.content === "string"
            );
          })
          .slice(-MAX_HISTORY_MESSAGES)
          .map((item) => ({
            role: item.role,
            content: item.content.slice(
              0,
              MAX_MESSAGE_LENGTH
            )
          }))
      : [];

  if (!message) {
    return jsonResponse(
      {
        error: "No message was provided."
      },
      400
    );
  }

  if (message.length > MAX_MESSAGE_LENGTH) {
    return jsonResponse(
      {
        error: "The message is too long."
      },
      413
    );
  }

  /*
   * The forbidden message is intercepted before Sally's AI model sees it.
   * This reduces the chance that the model will repeat the name.
   */
  if (containsForbiddenName(message)) {
    return jsonResponse({
      type: "death",
      text:
        "Sally goes perfectly still. Then she bolts into the passage " +
        "without looking back. You follow before the opening can close. " +
        "The corridor turns twice, narrows, and ends at a door already " +
        "standing open. Something inside has been waiting for a name to " +
        "be spoken."
    });
  }

  if (!env.AI) {
    console.error(
      "The Workers AI binding named AI is missing."
    );

    return jsonResponse(
      {
        type: "reply",
        text:
          "The wall trembles, but no voice passes through it."
      },
      500
    );
  }

  const messages = [
    {
      role: "system",
      content:
        SALLY_PROMPT +
        "\n\nCURRENT CONVERSATION TURN:\n" +
        String(turnNumber) +
        "\nUse this only to judge whether Sally is becoming restless. " +
        "Never mention the turn number to the visitor."
    },
    ...history,
    {
      role: "user",
      content: message
    }
  ];

  try {
    const result = await env.AI.run(
      MODEL,
      {
        messages,
        max_tokens: 300,
        temperature: 0.9
      }
    );

    const raw =
      typeof result?.response === "string"
        ? result.response.trim()
        : "";

    const parsed = parseSallyResponse(raw);

    return jsonResponse(parsed);
  } catch (error) {
    console.error(
      "Workers AI error:",
      error
    );

    return jsonResponse(
      {
        type: "reply",
        text:
          "The voice falters. For a moment, there is only scratching " +
          "inside the wall."
      },
      502
    );
  }
}

function containsForbiddenName(message) {
  return FORBIDDEN_PATTERNS.some(
    (pattern) => pattern.test(message)
  );
}

function parseSallyResponse(raw) {
  const candidates = [];

  if (raw) {
    candidates.push(raw);

    const fenced = raw
      .replace(/^```json\s*/i, "")
      .replace(/^```\s*/, "")
      .replace(/\s*```$/, "")
      .trim();

    if (fenced !== raw) {
      candidates.push(fenced);
    }

    const firstBrace = raw.indexOf("{");
    const lastBrace = raw.lastIndexOf("}");

    if (
      firstBrace !== -1 &&
      lastBrace > firstBrace
    ) {
      candidates.push(
        raw.slice(
          firstBrace,
          lastBrace + 1
        )
      );
    }
  }

  for (const candidate of candidates) {
    try {
      const parsed = JSON.parse(candidate);

      if (
        parsed.type === "death" &&
        typeof parsed.text === "string" &&
        parsed.text.trim()
      ) {
        return {
          type: "death",
          text: limitText(
            parsed.text.trim(),
            1200
          )
        };
      }

      if (
        parsed.type === "reply" &&
        typeof parsed.text === "string" &&
        parsed.text.trim()
      ) {
        return {
          type: "reply",
          text: limitText(
            parsed.text.trim(),
            1200
          )
        };
      }
    } catch {
      /*
       * Try the next possible JSON candidate.
       */
    }
  }

  /*
   * If the small model fails to return valid JSON, treat its raw output as
   * ordinary Sally dialogue rather than crashing the page.
   */
  return {
    type: "reply",
    text:
      limitText(raw, 1200) ||
      "Sally does not answer. Something else breathes nearby."
  };
}

function limitText(value, maximumLength) {
  if (typeof value !== "string") {
    return "";
  }

  return value.slice(
    0,
    maximumLength
  );
}

function jsonResponse(data, status = 200) {
  return new Response(
    JSON.stringify(data),
    {
      status,
      headers: {
        "content-type":
          "application/json; charset=UTF-8",
        "cache-control":
          "no-store"
      }
    }
  );
}

Desktop is easier, by far. In fact, Sally is already deployed as a desktop/mobile webpage through the Worker URL.

The fastest route is:

Keep Sally running at the current Worker address.
Add a button or sliding panel to your desktop site that opens Sally.
Once that works, embed the same page inside the Android app using a WebView.

That avoids rebuilding the chat interface in Kotlin immediately.

Android deployment

The easiest Android implementation is not rewriting Sally natively yet. Put the existing Worker page inside a WebView.

Android officially supports displaying web applications inside a WebView; in Compose, the WebView is wrapped with AndroidView.

Ensure your manifest contains:

<uses-permission android:name="android.permission.INTERNET" />

Then create:

package com.yourpackage

import android.annotation.SuppressLint
import android.webkit.WebView
import android.webkit.WebViewClient
import androidx.activity.compose.BackHandler
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember
import androidx.compose.ui.Modifier
import androidx.compose.ui.viewinterop.AndroidView

@SuppressLint("SetJavaScriptEnabled")
@Composable
fun PrisonerSallyScreen(
    onClose: () -> Unit
) {
    val sallyUrl =
        "https://prisoner-sally.thesulfurgod.workers.dev"

    val webViewHolder = remember {
        arrayOfNulls<WebView>(1)
    }

    BackHandler {
        val webView = webViewHolder[0]

        if (webView != null && webView.canGoBack()) {
            webView.goBack()
        } else {
            onClose()
        }
    }

    AndroidView(
        modifier = Modifier.fillMaxSize(),

        factory = { context ->
            WebView(context).apply {
                webViewHolder[0] = this

                webViewClient = WebViewClient()

                settings.javaScriptEnabled = true
                settings.domStorageEnabled = false
                settings.allowFileAccess = false
                settings.allowContentAccess = false

                loadUrl(sallyUrl)
            }
        },

        update = { webView ->
            if (webView.url == null) {
                webView.loadUrl(sallyUrl)
            }
        }
    )
}

function normalizeSallyResponse(response) {
  /*
   * JSON Mode normally returns an object.
   */
  if (
    response &&
    typeof response === "object"
  ) {
    if (
      response.type === "death" &&
      typeof response.text === "string" &&
      response.text.trim()
    ) {
      return {
        type: "death",
        text: limitText(
          response.text.trim(),
          1200
        )
      };
    }

    if (
      response.type === "reply" &&

      response.text.trim()
    ) {
      return {
        type: "reply",
        text: limitText(
          response.text.trim(),
          1200

      };
    }
