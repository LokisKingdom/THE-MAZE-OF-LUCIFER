oh, is there a way to get a commit summary, with the title of the commit, and the description? like i think this was giving me only the title, or maybe only the description, if possible i would like both.

Yes. Git treats the first line as the commit title/subject, and anything after the blank line as the description/body.

Use this:

git log --pretty=format:"TITLE: %s%n%nDESCRIPTION:%n%b%n------------------------------------------------------------%n" > commit-history.txt

That creates commit-history.txt containing:

TITLE: Added EFSMB jukebox to homepage

DESCRIPTION:
Created desktop music component.
Added full album catalog.
Moved jukebox to the front page.

------------------------------------------------------------

TITLE: Updated video section

DESCRIPTION:
Added new produced music videos.
Improved navigation.

------------------------------------------------------------

If a commit has no description, the DESCRIPTION: area will simply be blank.

If you also want the date and full commit ID, use this more complete version:

git log --pretty=format:"DATE: %ad%nCOMMIT: %H%nTITLE: %s%n%nDESCRIPTION:%n%b%n------------------------------------------------------------%n" --date=local > full-commit-history.txt

That is probably the best Deepdive version because it preserves the date, exact commit, title, and full description.
